## 主要修正

- 自然连接改为“笛卡尔积、选择、投影”的组合。
- 关系模式最低要求明确为 1NF；“3NF 才可用”的模糊表述被改写。
- 为 SQL 字符串常量补齐单引号，修正 LIKE、IS NULL、UNION/ALL 等易混淆写法。
- 补齐 `(S#, C#)`、M:N 联系表、1:N 外键位置等设计题主外键。
- 删除课程关系中的重复“任课教师”属性，改由讲授联系表表达。
- 订单日期归入订单关系，数量归入订单明细关系。
- 修正医院设计题中科室保存医生姓名的多值问题。
- 正确化 SQL 查询中的多表连接条件、聚合条件和字符串常量。
- 修正原文档中的 `year(Tbirthday<1970)`、`bwhere`、`sourse`、`sc_copy` 等错误。
- 触发器缺少学生时改为 `SIGNAL` 拒绝插入，不再自动插入不完整学生记录。
- 存储过程输出参数通过 `SELECT ... INTO` 赋值。
- 账户管理改为 MySQL 8.0 推荐的 `CREATE USER` 后再 `GRANT`。
- 澄清普通视图不能创建普通 B+ 树索引。

## 去重

- 原网站基础题库中移除 2 道完全重复题目。
- 新增文档题目与基础题库按规范化题干逐题比对。
- 最终 589 道题中不存在规范化后完全相同的题干。
